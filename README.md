# Active Motion

This codebase is in its early stages of development and is expected to get to a somewhat functional form in the coming months.

### v0.1 under development

This version of the library is very limited in its functionality as it only allows for the creation of a single element at one time on the screen.

This version also doesn't work well on larger resolutions due to an unknown bug.

But it is a very good start and development is proceeding well.

✨ **Version 0.1 Has been tested for multiple element rendering and higher resolutions and is fully functional with both.**
